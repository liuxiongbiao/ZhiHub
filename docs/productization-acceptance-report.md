# ZhiHub 产品化验收报告

> 验收日期：2026-08-24
> 验收环境：Windows + Docker Desktop 全栈 14 个长驻服务 + 系统 Chrome
> 结论：**本地演示与产品评审就绪**

## 一、用户现在能直接看到什么

1. **安全演示入口**：登录页可直接选择管理员、一线坐席或备班坐席，不在浏览器中输入/保存演示密码；生产环境强制禁用。
2. **三幕演示中心**：知识回答→真实订单查询→敏感操作转人工，每幕都有引用、置信度、工具结果、排队估时或业务上下文作为证据。
3. **首页决策驾驶舱**：自动解决率、等待人工、待审退款、知识健康、待办事项和上线准备度全部来自真实接口。
4. **三栏坐席现场**：左侧队列、中间对话、右侧客户业务信息；可在会话内查订单、发货、创建工单/退款，不再只是“聊天页”。
5. **知识质量中心**：文档就绪度、检索信心、P95 耗时、低置信问题和下一步修复建议一屏可见。
6. **运营分析与深度任务**：从事件、趋势、审批时效和检索对照中生成可执行建议；DeepAgent 历史、步骤、资源消耗与终止原因可追溯。
7. **真实 Widget/人工协同**：匿名会话、双向 typing、消息时间戳、队列位置/估时、无坐席留言和坐席回复实时到达均已闭环。

## 三、关键验收数据

- 首页自动解决率：**84.6%**（已修复首屏身份加载竞态，不再误显示 0%）。
- 上线准备度：**100%**，每一项为后端真实检查。
- 知识文档基线：7/7 ready；演示订单 6、工单 2、退款审批 2（P0-3 运行后只增加幂等验收数据）。
- 知识队列：`tenant_id % 8` 稳定分片，worker `prefetch=1` + `-Ofair`，避免单租户独占。
- 前端体积：从 Element Plus 全量分包 937.88KB（gzip 约 302KB）降至最大 JS 109.63KB（gzip 42.79KB）。
- 密码链路：直接使用 pyca/bcrypt 5.0、成本因子 12，并限制 UTF-8 输入不超过 72 字节；300 组随机盐即时校验 300/300 通过，三个演示账号均经真实登录接口复验。

## 五、建议演示路径

1. 打开 `http://localhost/login`，选择“演示管理员”。
2. 在演示中心连续点两次“下一幕”，讲完知识、订单和人工协同。
3. 点“切换到坐席视角”，展示完整上下文与会话内业务办理。
4. 返回管理员，从首页进入“知识质量”和“运营分析”，用真实指标收尾。

详细操作见 `docs/demo-guide.md`，PRD 全量边界与证据见 `docs/PRD实现差距审计报告.md`。
